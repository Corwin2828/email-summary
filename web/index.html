服务器还没有初始化账号，请先运行 python -m src.auth_store bootstrap。

怎么填

  1. 账号一般填 owner 或 team。
  2. 密码是服务器上创建网页账号时设置的密码，不是 SSH 密钥密码。
  3. 登录失败时先检查大小写和空格；多次失败会短暂限制登录，等几分钟再试。

团队账号

客户询盘提示词

团队账号只能编辑 AEBBS 询盘提示词；不会看到私人邮箱配置。

怎么填

  1. “总结提示词”决定 AI 怎么整理邮件内容，例如提取客户、车型、产品需求和下一步动作。
  2. “过滤提示词”决定哪些邮件需要通知；AEBBS 企业邮箱建议写得保守一点，不确定就保留并通知。
  3. 修改后点击“保存提示词”。提示词会立即用于后续新邮件，已处理邮件不会自动重跑。

AEBBS 知识库文件

只允许编辑 knowledge/aebbs 内的 .md / .txt 文件，保存前会自动备份。

文件列表

怎么填

  1. 左边点已有文件可以编辑；点“新建”后先填写文件路径，例如 products/welcome-lights.md。
  2. 文件内容用普通中文写清楚即可：产品名称、适配车型、卖点、价格口径、不能承诺的内容都可以写。
  3. 保存后系统会自动备份旧文件；如果写错了，先别乱删文件，可以用备份恢复。

Owner 系统设置

完整邮箱、模型、Webhook 与运行配置。已填写的 API Key、密码和 Webhook 会直接显示，方便核对。

怎么填

  1. API Key、邮箱密码、Webhook 会直接显示当前值；需要替换时直接改成新值。
  2. 端口、秒数、开关按实际需要改。看不懂的运行项建议先保持原样，尤其是 WEB_HOST 和数据目录。
  3. 保存后会推送一条飞书/企业微信测试消息，并检查 DeepSeek API；运行配置仍需重启邮件服务才生效，重启成功会再推送启动通知。
